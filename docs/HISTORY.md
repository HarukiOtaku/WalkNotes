# History (CivicWalk → WalkNotes)

This project started on 2026-10-07 as CivicWalk, an on-device draft writer aimed at
Hong Kong 1823 street reports. A small on-device Gemma build is not reliable for
official paperwork (it invented a district from coordinates), so the product was
narrowed to **WalkNotes**: a walking notebook (description / impression / field note)
with a fog-of-war map. That is the current app.

The Gradle application id remains `com.civicwalk.app`.
